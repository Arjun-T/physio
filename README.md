# Physio

A lightweight, static UI prototype for physiotherapy home-visit booking and physiotherapist registration.

## Current scope
- Front-end only (HTML/CSS with minimal JavaScript).
- No persistence (no API calls, no data storage).
- No form-specific success/failure handling.
- No routing, state management, or dynamic availability matching.
- No validation beyond native browser constraints.
- Includes basic accessibility enhancements (`for` + `id`, landmarks, focus states, and ARIA labels/descriptions where appropriate).
